# Netflix Userbase Analysis

## 📌 About the Project

This project focuses on analyzing Netflix user data to understand user demographics, subscription preferences, and usage patterns.

The analysis explores factors such as country, gender, age, and subscription type to identify patterns and derive meaningful insights from the dataset.

## Objectives

- Analyze the distribution of Netflix users across different countries.
- Understand the popularity of different subscription plans.
- Analyze subscription preferences across different age groups.
- Examine the distribution of Netflix users by gender.
- Identify important patterns and trends in the user data.
- Provide recommendations based on the findings.

## Dataset

The project uses the **Netflix Userbase Dataset**, obtained from Kaggle.

The dataset contains information related to:

- User details and demographics
- Country
- Gender
- Age
- Subscription type
- Revenue
- User activity

The dataset was analyzed to identify patterns in user demographics and subscription preferences.

## 🔍 Analysis Performed

The project includes the following analyses:

### 1. 🌍 Country-wise User Analysis

Analyzed the number of Netflix users across different countries to identify countries with a higher concentration of users.

### 2. 💳 Subscription Type Analysis

Analyzed the distribution of users across Basic, Standard, and Premium subscription plans to understand subscription preferences.

### 3. 🌍📊 Country-wise Subscription Analysis

Compared Basic, Standard, and Premium subscriptions across countries to identify regional differences in subscription choices.

### 4. 👥 Age-wise Subscription Analysis

Analyzed subscription preferences across different age groups, with a focus on Premium subscription usage.

### 5. 🚻 Gender-wise User Analysis

Analyzed the distribution of Netflix users by gender to identify differences in user representation.

## 📊 Key Insights

The analysis provided the following key insights:

- 🇺🇸 **USA and Spain** showed a high concentration of Netflix users in the dataset.
- 💳 The **Basic subscription plan** was the most commonly used subscription type.
- 🇮🇹 **Italy** showed a higher preference for the Basic subscription compared with the other plans.
- 👥 Users in the **35–40 age group** showed higher usage of the Premium subscription.
- 🚻 The dataset showed a **higher number of female users** compared with male users.
- 🌍 Subscription preferences varied across different countries, highlighting regional differences in user behaviour.

## 💡 Recommendations

Based on the analysis, the following recommendations can be considered:

1. **Expand Localized Content**
   - Invest in region-specific content and collaborate with local creators.

2. **Enhance Personalization**
   - Improve recommendations based on users' preferences, subgenres, and interests.

3. **Monitor and Address Churn**
   - Identify users who may cancel their subscriptions and provide suitable retention offers.

4. **Invest in Emerging Markets**
   - Focus on regions with growing internet penetration and untapped potential.

5. **Improve Accessibility**
   - Provide more multilingual subtitles and dubbing to reach a wider audience.
